# 🛒 Amazon Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes Amazon sales data using **Python, SQL, and Microsoft Power BI** to identify sales trends, product performance, revenue patterns, and key business insights.

The project follows a complete data analytics workflow, including data cleaning and transformation using Python, data analysis using SQL, and interactive dashboard development using Power BI.

## 🎯 Objective

* Analyze overall sales performance
* Identify top-performing products
* Analyze sales and revenue trends
* Understand product-level performance
* Identify important business KPIs
* Create an interactive dashboard for data-driven decision-making

## 🛠️ Tools & Technologies

* **Python** – Data cleaning, transformation, and exploratory analysis
* **Pandas** – Data manipulation and preprocessing
* **SQL** – Data querying and business analysis
* **Microsoft Power BI** – Interactive dashboard and visualization
* **Power Query** – Data transformation
* **DAX** – KPI and calculated measures

## 🔄 Data Analytics Workflow

### 1. Data Cleaning & Preparation – Python

* Loaded the Amazon sales dataset using Pandas
* Checked for missing and duplicate values
* Cleaned and standardized the data
* Corrected data types
* Created required columns for analysis
* Prepared the cleaned dataset for SQL and Power BI

### 2. Data Analysis – SQL

SQL queries were used to analyze:

* Total sales and revenue
* Product performance
* Sales trends
* Top-performing products
* Category-wise performance
* Quantity sold
* Business KPIs

### 3. Dashboard Development – Power BI

The cleaned and analyzed data was used to create an interactive Power BI dashboard with:

* KPI cards
* Sales trend analysis
* Product performance analysis
* Category-wise analysis
* Revenue analysis
* Interactive slicers and filters
* Charts and visualizations

## 📊 Key KPIs

The dashboard focuses on important business metrics such as:

* **Total Sales**
* **Total orders**
* **Total Quantity Sold**
* **Average Sales**
* **Total Tax**
* **Shipping Cost**

## 🔍 Key Findings

* Identified top-performing products based on sales and revenue.
* Analyzed sales trends and revenue patterns over time.
* Compared product and category-level performance.
* Identified products contributing significantly to overall sales.
* Used business KPIs to understand overall sales performance.
